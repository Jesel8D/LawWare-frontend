# LawWare Frontend

Preparación de estructura para Next.js y TypeScript. No existe todavía una aplicación ejecutable, dependencias instaladas ni despliegue. La interfaz consumirá los contratos que establezca [LawWare-backend](https://github.com/Jesel8D/LawWare-backend); el modelo y las decisiones están en [LawWare-database](https://github.com/Jesel8D/LawWare-database) y [LawWare-context](https://github.com/Jesel8D/LawWare-context). Vercel es el alojamiento previsto, aún no validado.

El flujo futuro de privacidad está descrito en [docs/FLUJO_PRIVACIDAD.md](docs/FLUJO_PRIVACIDAD.md).
